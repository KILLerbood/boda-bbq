# BODA BBQ

Cinematic scroll website for BODA BBQ: a photoreal burger assembles layer by layer as you scroll, with the menu, build-your-burger, cart and WhatsApp ordering.

- English (default) and Saudi Arabic (RTL)
- Static site, no build step: open `index.html` through any static server, e.g. `python3 -m http.server`
- Set the WhatsApp number in `js/data.js` (`CONFIG.whatsapp`, digits only, e.g. `9665XXXXXXXX`)
